# GBFR Local Translator

Technical candidate `v0.2.0-beta.5-tech` for the GBFR Vietnamese localization pipeline.

The Vietnamese project overview, validation steps, CodeGraph setup, and release-gate policy are documented in [README_VI.md](README_VI.md).

This repository intentionally excludes game `.msg` files, `data.i`, packaged builds, local CodeGraph databases, and the full private translation corpus.
